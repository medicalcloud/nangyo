# 蔵府配像第五

## 単位

- [032](032.md) 第32難　三十二難曰五蔵倶等而心肺独在膈上者何也然心者血肺
- [033](033.md) 第33難　三十三難曰肝青象木肺白象金肝得水而沈木得水而浮肺
- [034](034.md) 第34難　三十四難曰五蔵各有声色臭味可暁知以不然十変言肝色
- [035](035.md) 第35難　三十五難曰五蔵各有所府皆相近而心肺独去大腸小腸遠
- [036](036.md) 第36難　三十六難曰蔵各有一耳腎独有両者何也然腎両者非皆腎
- [037](037.md) 第37難　三十七難曰五蔵之気於何発起通於何許可暁以不然五蔵

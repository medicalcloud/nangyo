# 難経（王翰林集註）原文・注・現代語訳

『難経』（『王翰林集註黄帝八十一難経』，四部叢刊本）の原文を，難ごとの小さな単位に分け，資料間の異同（校異）・校訂，集註と滑寿の注，日本語訳，解説を付けて，人にも機械にも読みやすい形にしたもの。

全81難について，句読点を付けた原文，校異・校訂・注釈，集註（原文），滑寿注（原文），日本語訳（原文・集註・滑寿注の訳と解説）がそろっている。英訳はない。

## 構成

```
NN_篇名/
  index.md      単位の一覧
  NNN.md        原文（句読点つき）＋校異・校訂・注釈＋集註（原文）＋滑寿注（原文）
  NNN.ja.md     日本語訳：原文の訳・集註の訳・滑寿注の訳・解説
```

- 篇は 01〜13（楊玄操の十三篇），00（序・目録と『難経本義』の付属の部分），14（跋・釈音）。
- 単位の番号は難の番号（001〜081）。00 と 14 は p001 などの番号で，序と跋だけに訳がある。目録・釈音・提要・凡例・彙考・闕誤総類・図説は原文のみで，句読点も付けていない。
- 注の位置は，原文のファイルでは〔…本文の末尾の字〕，訳では〔「本文の句」について〕で示す。注の原文に句読点は付けていない。

### ファイルの頭の情報（YAML）

| キー | 内容 |
|---|---|
| book | 書名 |
| chapter / chapter_title | 篇の番号と篇名 |
| unit | 単位の番号（ファイル名） |
| clause | 難の番号 |
| title | 単位の題 |
| punctuated | 原文に句読点を付けたか |
| no_ja | 訳がない単位 |

訳のファイル（`.ja.md`）の頭には `unit` `clause` `lang` `source`（対応する原文のファイル）を付けている。

### 訳と解説の書き方

- 訳は直訳を基本とし，補った語は〔〕に入れた。
- 集註の訳では，注者を「呂広：」「丁徳用：」「楊玄操：」「虞庶：」のように示した。底本で注者の名がない注はそのままにした。
- 解説は一般的な解釈を独自の言葉でまとめたもので，現代の注釈書からの引用はしていない。
- 底本の字が疑わしいところは〔底本は「X」〕と注記した。「別本」は，中醫笈成の『難經集註』と殆知閣の『难经集注』を指す。
- 文意が取れないところは〔文意不明〕などと記し，推測で埋めていない。
- 訳語と表記は，傷寒論・金匱要略などと同じ方針である。

## 底本と，本文の補い・訂正

### 底本

- **どのような本か**：『王翰林集註黄帝八十一難経』五巻の四部叢刊本。明の王九思らが集めた，呂広・楊玄操・丁徳用・虞庶・楊康侯の注を持つ。序（楊玄操）・目録・巻末の釈音と，天瀑（林述斎）の跋がある。
- **どのように入手したか**：漢籍リポジトリ（Kanripo）が GitHub で公開している，四部叢刊本を入力した電子テキスト（KR3e0003。句読点のない本文）を使った。図の丁は電子テキストにないので，図は入っていない。
- **本文と注の分け方**：行の字下げでは分けられないので，『難經集註』（中醫笈成）の段落と他の資料の本文の字の並びに照らして機械的に分け，全篇を読んで直した。
- **字の変換**：旧字・異体字を日本の新字体に直した（方針は `字体と変換の方針.md`）。Kanripo の外字は，KR-Gaiji の字形の画像と文脈で字を当てた。本文の「巳」は，文意に従って「已」または校訂で「己」とした。

### 底本に足りないところ

- 底本と滑寿本の欠字は，他の資料で補い，【補】と記した。
- 第2難の集註の末は，図の丁の前で文が切れている。

### 訂正（校訂）

- 本文を改めたのは67か所（付属部分の補いは含まない）。資料を比べて一番それらしい字を採り，改めたところには【校訂】として，元の字句・各資料の字・改めた理由を記した。
- 「大」と「太」，「柰」と「奈」のような通用字，文意が同じ異文は改めず，校異に記した。

### 照合した資料

- **滑寿『難経本義』**：Kanripo（KR3e0004）の文淵閣四庫全書本。元の注釈書で，本文の照合と注に使った。欠字は中醫笈成本で補った。
- **中醫笈成**『八十一難經』『難經集註』『難經本義』など。
- **Wikisource**（中文維基文庫）『難經』。
- **殆知閣**『八十一难经』『难经集注』など。
- **徐大椿『難經經釋』，葉霖『難經正義』などの注釈書**：語句の解釈を確かめるのに使った。
- **校異**：これらの資料と底本の字句の違い。「X は「…」に作る」の形で，どの資料かを示す。字体だけの違い・句読点・他の資料の欠落は記していない。
- **注**：底本の本文と注を機械的に分けたので，注の位置に誤りがありうる。
